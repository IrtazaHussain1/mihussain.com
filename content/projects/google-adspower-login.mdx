## Problem

The client needed to run browser logins across a large pool of accounts, and doing it by hand or with one-off scripts didn't scale:

- Every account needed its own isolated browser profile and a proxy in a matching location.
- Logins failed in many different ways, and nobody could easily see which step broke or why.
- There was no single place to start a batch, check its progress, or look back at past runs.
- State was spread across tools, so sessions that had quietly signed out went unnoticed.

---

## Approach

I built a production API that sits on top of AdsPower and treats the browser fleet as something you operate, not a pile of scripts.

1. **One API for every run.** Single logins and batches go through the same endpoints, with parallel workers so large batches finish in reasonable time.
2. **Geo-aligned proxies.** Each account is paired with an AdsPower profile and a proxy in the account's location, with fallbacks when a proxy isn't available.
3. **Central state.** Accounts, profiles, proxies, runs and every step of every attempt are stored in one place, so failures can be traced without replaying a session by hand.
4. **Scheduled upkeep.** Background jobs check whether sessions are still signed in, reopen them with backoff, and free up resources that are no longer in use.
5. **Visibility.** API docs for operators, step-level logs and Grafana dashboards so problems show up before someone has to ask.

The layers are kept separate: Python handles orchestration, AdsPower handles browser isolation, and Xano holds durable state. Each one can scale on its own.

---

## Stack

| Area | What I used |
|------|-------------|
| **API** | Python, Flask, Gunicorn, Flasgger (Swagger docs) |
| **Browser automation** | Selenium 4, AdsPower local API |
| **State** | Xano as the central store for accounts, proxies, runs and attempts |
| **Scheduling** | APScheduler for session checks and maintenance jobs |
| **Config** | Pydantic, python-dotenv |
| **Monitoring** | Grafana dashboards |
| **Deploy** | Docker, Docker Compose, PM2 |
